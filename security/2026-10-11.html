🤖 AI Tools & Frameworks High Priority

CVE-2026-105192 — LMCache Unauthenticated RCE (NO PATCH)

CRITICALCVSS 9.8PoC publicNo fix

In LMCache multiprocess (distributed) mode — the KV-cache layer bolted onto vLLM — the server opens an unauthenticated ZeroMQ ROUTER socket on port 5555. Messages with msgpack extension code 1 are passed to pickle.loads() before the message type is checked. A single crafted ZMQ DEALER message executes code as the LMCache process user; official container images run as root. Default bind is 127.0.0.1, but operators routinely set --host to a routable address when scaling vLLM — that shape is unauthenticated network RCE.

Affected: LMCache 0.3.9 – 0.5.5, all 0.5.6 RCs, dev branch
Status: Disclosed by JFrog Oct 7, 2026 — no fixed release, no vendor advisory.
Mitigation: no routable address; firewall port 5555; NetworkPolicy to vLLM workers only.
Source: threatfrontier.com/articles/lmcache-pickle-rce-cve-2026-105192-no-fix
